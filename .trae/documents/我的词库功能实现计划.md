# 「我的词库」功能实现计划

## 一、摘要

在现有纯前端词库站（`template.html` → `build.py` 注入数据 → `index.html`）中新增第四块能力「我的词库」：

1. 任意词库（All / KET / PET / PEP）勾选单词，批量加入我的词库；
2. 我的词库按 **未掌握 / 已掌握 / 错题库** 三个状态分栏；
3. 未掌握、错题库的单词可一键标记为已掌握；
4. 未掌握词库按「每天 3–10 个」一键生成**每日任务队列**学习计划；
5. 我的词库支持两种浏览模式：**列表模式**（沿用现有卡片栅格）与**单卡浏览模式**（单词、音标、自然拼读拆分、例句、单词发音、例句发音、上一个/下一个）；
6. 数据存储：**localStorage + JSON 导入/导出**（用户已确认），并新增**自测模块**（看词选义，答错进错题库），不做 Firebase。

所有改动集中在 `template.html`，改完后运行 `python build.py` 重新生成 `index.html`；不修改数据 JSON 与构建脚本逻辑。

## 三、数据设计

### 3.1 存储位置与键

- 新键：`ebbwords.mylib.v1`（与偏好 `ebbwords.v1` 分离，避免偏好写入时误覆盖词库）。
- 结构：

```json
{
  "version": 1,
  "words": {
    "apple": {
      "w": "apple", "p": "n", "i": "ˈæpl", "c": "苹果",
      "a": null, "t": "food", "g": "n", "l": "A",
      "tn": "食物饮料", "tc": "#dd6b20",
      "status": "unmastered",
      "addedAt": 1762732800000,
      "updatedAt": 1762732800000,
      "streak": 0,
      "wrongCount": 0
    }
  },
  "plan": {
    "daily": 5,
    "days": [{ "keys": ["apple", "able"], "done": ["apple"] }],
    "cursor": 0,
    "createdAt": 1762732800000
  }
}
```

- 单词主键：复用 `selKey(w)`（小写、trim 后的词面），保证跨 All/KET/PET/PEP 同一单词不重复入库。
- 入库时保存**词条快照**（含 `tn/tc` 主题名与颜色），这样即使我的词库不依赖当前 `DATA.groups` 也能正确渲染卡片。
- 状态枚举：`unmastered`（未掌握）、`mastered`（已掌握）、`wrong`（错题库）。错题库是独立状态，不重复计数。

### 3.2 数据层函数（新增，放在 `openWordModal` 之前的公共区）

```js
const MYLIB_LS = "ebbwords.mylib.v1";
let MYLIB = { version: 1, words: {}, plan: null };

loadMyLib() / saveMyLib()                 // try/catch，配额或隐私模式失败时 toast 提示
myKey(w)                                  // = selKey(w)
snapshotWord(w)                           // 复制 w 并补 tn/tc
myRecords(status)                         // 按状态取记录；未掌握按 addedAt 升序，其余按 updatedAt 降序
myCounts()                                // { unmastered, mastered, wrong }
addToMyLib(words, status="unmastered")     // 已存在则补全缺失字段并按需更新状态，返回 {added, updated}
setMyStatus(key, status)                  // 更新 status/updatedAt
removeMyWords(keys)                       // 批量删除
```

行为约定：
- 重复加入不产生副本；已有记录缺 `i/c/p/a` 时从新词条补全（与 `buildAllBook` 的 `enrich` 一致）。
- 状态变化统一走 `setMyStatus`，保证 `updatedAt` 与视图刷新一致。

## 四、界面与交互设计

### 4.1 导航与新栏目

  - 右侧操作：`学习计划`、`自测`、`导出`、`导入`；

- 进入我的词库时：隐藏工具栏 `#dims`（主题/词性/字母/发音/词根）与 `#chipsWrap`（状态页签替代分类 chips），保留搜索框与英音/美音切换。

### 4.2 我的词库数据源

`myBook()`：把 `MYLIB.words` 中当前 `state.myStatus` 的记录转成 `{...rec, id: 序号}` 的临时 book：

```js
{ id: "my", name: "我的词库", short: "my", kind: "my",
  groups: 由记录 tn/tc 聚合出的唯一主题, words: [...] }
```

- `currentBook()` 增加 `state.lib === "my"` 分支。
- `syncBook()` 照常建立 `groupMap`，`topicName/topicColor` 因此可用。
- `filtered()` 增加 my 分支：只做关键词匹配（状态已由 `myBook` 过滤），不再走 `state.cat/dim`。
- `renderGrid()` 的统计文案改为：`我的词库 · 未掌握 12 词 · 已掌握 5 · 错题 3`。
- `#empty` 文案按场景动态设置：我的词库为空时提示「去 All/KET/PET/PEP 勾选单词后点“加入我的词库”」。

### 4.3 批量加入我的词库（需求 1）

- 选择上限从 10 调整为 `MY_PICK_MAX = 300`：`toggleSelect()` 与 `updateSelBar()` 同步修改；底部显示「已选 X」，超过 10 时补「（默写纸取前 10）」。
- `generateSheet()` 改为取选中项前 `PRINT_MAX`(10) 个，保证默写纸原有行为不破坏。
- 底部 dock 新增按钮：
  - `#btnAddLib`「加入我的词库」：普通词库可见，选中 ≥1 时可用；点击后全部以 `unmastered` 入库，toast「已加入 N 个单词」，清空选择。
  - `#btnMyMaster`「移入已掌握」、`#btnMyRemove`「移出词库」：仅我的词库可见，作用于当前选中项。
- `applyBook()` 负责按当前 lib 切换这三个按钮的 `hidden/disabled`。

### 4.4 三栏状态与「标记已掌握」（需求 2、3）

- `#mybar` 点击切换 `state.myStatus` → 重建 `DATA` → `renderMybar()` + `renderGrid()`，`browseIdx` 归零。
- 列表模式下，我的词库卡片右侧按钮区改为纵向 `.acts`：
  - 播放按钮（原有）；
  - 非已掌握状态追加 `✓` 按钮（`data-master`），点击 `setMyStatus(key,"mastered")`，toast「已标记为已掌握」，刷新计数与列表。
- 单卡浏览模式下提供「标记已掌握」按钮（`mastered` 状态时隐藏/置灰）。

### 4.5 两种浏览模式（需求 5）

`#mybar` 增加列表/卡片切换（`data-my-browse`），持久化到偏好。

- **列表模式**：现有 `.grid` 卡片栅格；点击单词仍打开原有详情弹窗，勾选用于批量操作。
- **单卡浏览模式**：`renderGrid()` 在 `lib==="my" && myBrowse==="card"` 时改调 `renderSingle()`，在 `#grid` 内渲染一张大卡片：
  - 顶部：`第 i / N 个` + 状态标签；
  - 内容：复用 `segmentedHtml()`（自然拼读高亮）、`syllableHtml()`（音节）、音标/词性、中文释义、`makeSentence()` 例句中英文；
  - 按钮：`播放单词`（`playWord`）、`播放例句`（新增 `playSentence`）、`标记已掌握`、`← 上一个`、`→ 下一个`；
  - `state.browseIdx` 越界时循环；切换状态/搜索时归零；卡片模式下监听键盘 `ArrowLeft/ArrowRight`（弹窗未打开时生效）。
- **例句发音**：新增

```js
function playSentence(text) // 有道 dictvoice?type=2&audio=<encodeURIComponent(sentence)>
                            // onerror / play reject → speechSynthesis（en-GB）
```

  与 `playWord` 共享互斥逻辑（播放新音频前暂停旧的 `audioEl`）。

### 4.6 每日任务队列学习计划（需求 4）

入口：`#btnPlan`；新增 `#planModal`，内容由 `renderPlan()` 动态生成。

- 无计划时：显示未掌握总数、每日数量选择（3–10，默认 `state.planDaily`）、`生成计划`。
- 生成规则：`myRecords("unmastered")` 按加入顺序切块，每天 `daily` 个，写入 `MYLIB.plan = {daily, days, cursor:0}`。
- 有计划时：
  - 头部：`共 X 词 · 每天 N 个 · 第 k / T 天`；若未掌握池中新增了不在计划里的词，提示「有 N 个词不在计划中，可重新生成」。
  - 今日任务列表：单词、音标、中文、播放按钮、`认识`、`不认识`。
  - `认识` → `setMyStatus(key,"mastered")`；`不认识` → `setMyStatus(key,"wrong")` 且 `wrongCount+1`；两者都把 key 记入当前天 `done`。
  - 当天全部处理完显示「今日完成 🎉」+`进入下一天`（`cursor+1`）。
  - 计划结束显示「计划已完成」+`重新生成`。
  - `重新生成` 需 `confirm`，会按当前未掌握池重建计划。
- 计划中已被删除的词条自动跳过，保证渲染不报错。

### 4.7 自测模块（用户选定，错题库来源）

入口：`#btnQuiz`；新增 `#quizModal`，由 `renderQuiz()` 管理状态。

- 范围选择：`错题库` / `未掌握` / `全部`，默认错题库非空则错题库，否则未掌握；空池显示提示。
- 每组 10 题（池不足则取全部），题目随机抽样。
- 题型：看词选义。题干显示单词 + 自然拼读高亮 + 音标 + 播放按钮；4 个中文释义选项（1 正确 + 3 干扰项）。
  - 干扰项来源：我的词库其他词条的 `c`；不足 4 个时从全局 `EBB` 词库补齐；过滤空释义与「（无释义）」。
- 判定规则：
  - 答错 → `setMyStatus(key,"wrong")`、`streak=0`、`wrongCount+1`；选项标红并高亮正确项；
  - 答对 → `streak+1`；连续答对 2 次 → `setMyStatus(key,"mastered")` 并 toast 提示；
  - 每题反馈后 900ms 自动下一题。
- 结束页：正确数 / 题数、正确率、`再来一组`、`关闭`。关闭/结束时同步刷新 `#mybar` 计数与列表。

### 4.8 导入 / 导出（数据安全）

- 导出：下载 `ebbwords-mylib-YYYYMMDD.json`，内容 `{app:"EbbWords", version:1, exportedAt, words, plan}`。
- 导入：隐藏 `<input type="file" id="myImportInput" accept="application/json">`；读取后校验 `words` 为对象。
  - 确认后合并：不存在则新增；已存在则仅当导入记录 `updatedAt` 更新时覆盖状态与计数，词条字段缺失则补全；
  - 本地已有计划时保留本地计划，仅在本地无计划时采用文件中的计划；
  - 结果 toast「导入完成：新增 X，更新 Y」；解析失败 `alert("导入失败：文件格式不正确")`。

## 六、假设与决策

1. **存储**：localStorage（键 `ebbwords.mylib.v1`）+ JSON 导入导出；不做账号、不做云同步。风险（换设备/清缓存）由导入导出兜底，并在我的词库页提示。若后续要同步，数据层已集中在 `loadMyLib/saveMyLib` 与状态函数中，替换为云端只需改这几处。
2. **单词身份**：以词面（小写 trim）为唯一键，与现有 `selKey` 一致，跨词库去重。
3. **错题库入口**：按用户选择实现自测模块（答错进入）；另外学习计划中「不认识」也进入错题库（否则计划无法推进）。
4. **已掌握判定**：自测连续答对 2 次自动移入已掌握；同时保留手动「标记已掌握」。
5. **例句**：沿用现有 `makeSentence()` 生成逻辑，不新增数据字段；例句发音使用有道 `type=2`，失败回退 `speechSynthesis`。
6. **我的词库筛选**：隐藏主题/词性等维度筛选，只保留状态页签 + 搜索 + 口音，降低儿童 Pad 端操作复杂度。
7. **默写纸**：选择上限提高后仍只取前 10 个生成，保持原有 A4 模板不变。
8. **导入冲突**：按 `updatedAt` 新者优先；已有本地计划时不被文件覆盖。
