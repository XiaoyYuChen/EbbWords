# 听写功能、默写纸自动入库、新增短文 实现计划

## Summary

在现有纯前端词库站（`template.html` → `build.py` 注入数据 → `index.html`）中新增三项能力：

1. **听写**：选中单词后，可按设定把每个单词朗读 N 遍（默认 3 遍），每遍之间、单词之间都间隔 X 秒（默认 10 秒），按选中顺序循环播放。
2. **默写纸自动入库**：点击「生成默写纸」时，本次默写纸实际使用的单词自动加入「我的词库 · 未掌握」；已存在的单词保留原状态（尤其不把「已掌握」重置为「未掌握」）。
3. **新增短文（网页运行时）**：短文列表页提供「新增短文」入口，输入标题和正文后保存到浏览器 `localStorage`；新增短文立即出现在列表并可打开。**此功能完全在已发布的网页上运行，不依赖 `build.py`、不写服务器文件、不需要重新构建。** 正文单词、单词列表 chip 均可点击，复用现有单词弹窗的全部能力（音标、自然拼读、例句、发音、加入我的词库、加入默写纸）。现有词库和内置短文词表中没有的生词，点击时在浏览器端调用支持跨域的免费词典/翻译接口补全，并缓存到本地。

开发侧改动集中在 `template.html`；发布前需运行一次 `python build.py` 生成 `index.html`。**这次构建只是把新代码发布出去，之后用户在网页上新增短文时不再需要也无法运行 `build.py`。**

### 2. 生成默写纸时自动加入「我的词库 · 未掌握」

**文件**：[template.html](file:///d:/AIProjects/EbbWords/template.html#L2967-L2977)

修改 `generateSheet(blank)`：

```js
function generateSheet(blank) {
  const words = blank ? [] : [...state.selected.values()].slice(0, PRINT_MAX);
  if (!blank && !words.length) return;
  if (!blank) {
    // 只新增词库中不存在的单词，已存在（含已掌握）保留原状态
    const missing = words.filter((w) => {
      const k = myKey(w);
      return k && !MYLIB.words[k];
    });
    if (missing.length) {
      addToMyLib(missing, "unmastered");
      refreshMyViews();
      toast(`已将 ${missing.length} 个新词加入未掌握`);
    }
  }
  // ...原有 canvas 绘制与弹窗逻辑不变
}
```

**决策**：只处理默写纸实际使用的单词（前 `PRINT_MAX=10` 个），不是全部 300 个已选词；空白模板（`generateSheet(true)`）不入库。

**为什么用过滤后再调用 `addToMyLib`**：现有 `addToMyLib` 对已存在记录会把 `status` 改为传入状态，直接调用会重置已掌握词；先过滤即可保留原状态且复用现有去重、快照逻辑。

#### 3.4 生词运行时联网查询（CORS 已实测）

**文件**：[template.html](file:///d:/AIProjects/EbbWords/template.html#L3078-L3100) `openPassageWord` 附近新增。

查询顺序：

1. `findWordAnyLib(key)`（KET/PET/PEP 全部词库）；
2. `EBB.passages.wordMap[key]`（构建时已缓存的内置短文生词）；
3. `RUNTIME_WORDS[key]`（用户之前查询过的自定义短文生词）；
4. 都没有 → 调用 `fetchRuntimeWord(key)` 联网查询。

`fetchRuntimeWord(word)` 逻辑：

- 请求 `https://api.dictionaryapi.dev/api/v2/entries/en/{word}`：
  - `i` 取 `phonetics` 中第一个非空 `text`，否则取顶层 `phonetic`；
  - `p` 取第一条 `meanings[].partOfSpeech` 并映射为 `n/v/adj/adv/...`；
  - `e` 取 `meanings[].definitions[].example` 中第一个非空例句；
  - 取不到音标/例句时对应字段留空。
- 中文释义：请求 `https://api.mymemory.translated.net/get?q={word}&langpair=en%7Czh-CN`，取 `responseData.translatedText` 作为 `c`；若返回值含 `MYMEMORY WARNING` 或与单词相同则视为失败。
- 若存在英文例句 `e`，再用 MyMemory 翻译一次得到 `z`；例句翻译失败不影响主流程，`z` 留空。
- 任一接口失败/超时（`AbortController` 6 秒）时返回 `null`。
- 成功后写入 `RUNTIME_WORDS` 并 `saveRuntimeWords()` 缓存，下次点击不再请求。

`openPassageWord(word)` 改为异步流程：

```js
async function openPassageWord(word) {
  const key = String(word || "").toLowerCase().trim();
  if (!key) return;
  const lib = findWordAnyLib(key);
  if (lib) { openWordModal(lib); return; }
  const cached = (EBB.passages.wordMap || {})[key] || RUNTIME_WORDS[key];
  if (cached) { openWordModal(toWordObj(cached, word)); return; }

  // 先打开“查询中”占位弹窗
  openWordModal({ w: word, i: "", c: "", p: "", loading: true });
  try {
    const fetched = await fetchRuntimeWord(key);
    if (fetched) {
      RUNTIME_WORDS[key] = fetched;
      saveRuntimeWords();
      if (isCurrentWord(key)) openWordModal(toWordObj(fetched, word));
    } else if (isCurrentWord(key)) {
      openWordModal({ w: word, i: "", c: "（未收录）", p: "" });
    }
  } catch (e) {
    if (isCurrentWord(key)) openWordModal({ w: word, i: "", c: "（未收录）", p: "" });
  }
}
```

- `isCurrentWord(key)`：判断当前弹窗仍是该单词，避免用户已关窗或切换单词后被异步结果覆盖。
- `toWordObj(cached, word)`：把词表/缓存对象规范成 `{w,p,i,c,e,z}`。
- 同一单词并发点击用 `runtimeFetching` Map 去重，避免重复请求。

### 4. 发布与构建边界（重要）

**文件**：[build.py](file:///d:/AIProjects/EbbWords/build.py#L1209-L1219)

本次代码改动发布流程：

1. 修改 `template.html`；

用户侧使用流程（与 `build.py` 无关）：

1. 打开已发布网页 → 短文 → 「＋ 新增短文」；
2. 输入标题与正文 → 保存；

**边界说明**：

- 若需要把自定义短文变成所有访客可见的内置短文，仍需开发者手动放入 `data/passages` 并重新构建，这属于可选的后台流程，不是本功能的运行前提。

## Assumptions & Decisions

1. **听写间隔**：用户已确认「两处都加间隔」——同一单词两次朗读之间、以及一个单词读完后进入下一个单词前，都等待设定秒数。
2. **听写默认值**：每个单词 3 遍、间隔 10 秒；设置值持久化到现有偏好 `ebbwords.v2`。
3. **听写顺序**：按 `state.selected` 的插入顺序（即选词顺序）播放；不随机。
4. **听写不显示单词**：只显示「第 i/N 个 · 第 r/R 遍」进度，避免提示答案。
5. **默写纸自动入库范围**：只加入默写纸实际展示的前 10 个单词，不是全部已选词。
6. **已存在单词状态**：用户已确认保留原状态不变；实现上只对 `MYLIB.words` 中不存在的词调用 `addToMyLib`。
7. **新增短文存储**：用户已确认使用浏览器 `localStorage`，键 `ebbwords.passages.v1`，不清除内置 36 篇。
8. **新增短文完全运行时完成**：用户已明确“网页发布后无法运行 build.py”；因此新增短文不读写 `data/`，不调用构建脚本，所有持久化与生词查询都在浏览器内完成。
9. **运行时生词查询**：用户已确认对现有词库/词表中没有的单词做联网查询；使用支持 CORS 的 `dictionaryapi.dev`（音标/词性/英文例句）+ MyMemory（中文翻译），结果缓存到 `ebbwords.passagewords.v1`。
10. **查询失败兜底**：离线、接口限流、404 时显示「（未收录）」，不阻塞短文阅读与词表操作。
11. **自定义短文 ID**：使用字符串 `"c"+时间戳`，与内置数字 ID 区分；所有查找改为字符串比较。
12. **新增短文不做编辑/删除**：本次只实现“新增 + 查看”，不增加编辑、删除、排序功能，避免超范围。
13. **短文入口位置**：新增按钮只出现在短文列表页标题行，不进入 `libbar`，不污染现有词库切换逻辑。
